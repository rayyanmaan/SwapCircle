# SwapCircle Codebase Documentation

This is the main documentation file for the SwapCircle project. It provides an overview and directs to detailed documentation for specific features and components.

## Project Structure

- **Frontend**: Next.js application located in `Frontend/`
- **Backend**: Python FastAPI application located in `Backend/`
- **Documentation**: Project documentation located in `Documentation/`

## Key Features

### Frontend Features
- **Theme System**: See [theme.md](./theme.md) for font and styling information
- **Logo Component**: See [components.md](./components.md) for logo implementation
- **Components**: See [components.md](./components.md) for component documentation

### Backend Features
- See `Documentation/backend-architecture.md` for backend documentation

## Making Changes

Before making any changes:
1. Consult this codebase folder for relevant documentation
2. Review existing code to ensure changes don't break functionality
3. Update relevant documentation files after making changes
